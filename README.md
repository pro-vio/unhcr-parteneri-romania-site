# Rețeaua de parteneri UNHCR în România

Site public cu **structura de raportare** a unui studiu de analiză de conținut pe
comunicarea publică a organizațiilor partenere UNHCR în România, 2022–2026.

→ https://pro-vio.github.io/unhcr-parteneri-romania-site/

## Ce e aici

Doar pagina: metodă, întrebări de cercetare, definiții de lucru, schema de codare,
structura celor șapte taburi de rezultate, și limitele declarate.

## Ce nu e aici

Datele. Materialele de lucru — corpusul de postări, codebook-ul operațional,
registrul metodologic, fișa de arbitraj — sunt într-un depozit privat, întrucât
includ date personale ale terților și material academic nepublicat.

Lista de organizații reproduce doar denumirea, tipul atribuit de UNHCR și județul.
Datele de contact din registrul de parteneri nu sunt reproduse.
